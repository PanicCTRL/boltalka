# TODO_SPLIT_FRACTAL.md — Архитектура и дорожная карта робота split_fractal

## 1. Базовые параметры инструмента и таймфрейма
- **Таймфрейм свечей**: **M5 (300 секунд / 5 минут)** (`period_time = 5`).
- **Таймер свечи**: Отсчет 5-минутного интервала по биржевому времени (сделки из `OnAllTrade`).
- **Рынок / Класс**: Срочный рынок Московской Биржи (`SPBFUT`), класс `SPBFUT`, инструмент `MXU6` (фьючерс IMOEX).

---

## 2. Модель хранения свечей в памяти (MetaTrader / TradingView Style)
- **Индексация от текущей к старым**:
  - `candles[1]` — **текущая формирующаяся свеча** (live-бар, обновляется каждым тиком: High, Low, Close).
  - `candles[2]` — **предыдущая закрытая свеча** (1 бар назад).
  - `candles[3]` — **2 бара назад** (центральная свеча фрактала Билла Вильямса).
  - `candles[i]` — **i-1 баров назад** (например, `candles[35]` — бар, закрывшийся 34 свечи назад).
- **Сдвиг массива при закрытии бара**:
  - Каждые 5 минут при закрытии свечи выполняется сдвиг: новая чистая свеча вставляется в начало `candles[1]`, все старые сдвигаются на `+1`.
  - Старые свечи за пределами буфера (история вчерашнего дня + текущего, ~360–500 баров) плавно удаляются из хвоста.
- **Поля свечи**:
  ```lua
  candle = {
      time  = "100500",  -- время бара (ЧЧММСС)
      open  = 2850.0,
      high  = 2855.5,
      low   = 2848.0,
      close = 2852.5
  }
  ```

## 3. Аналитические блоки и математика

### 3.1. Первый регрессионный тренд (базовый / свинг)
- Строится по последним $N$ свечам (например, от `candles[1]` до `candles[30]`) или по последнему свингу фракталов.
- Показывает локальный наклон движения и границы канала.

### 3.2. Индикатор MACD и детектор дивергенций
- Расчет по ценам закрытия массива `candles`.
- Поиск двух пиков/впадин:
  - Первый экстремум на баре `candles[k]` (например, 35 баров назад).
  - Второй экстремум на баре `candles[m]` (например, 8 баров назад).
- Определение бычьей / медвежьей дивергенции при расхождении экстремумов цены и гистограммы MACD.

### 3.3. Второй регрессионный тренд (по дивергенции MACD)
- Натягивается строго между двумя найденными точками дивергенции:
  - Старт: первый пик дивергенции (`candles[k]`).
  - Конец: второй пик дивергенции (`candles[m]`) или текущий бар (`candles[1]`).
- Служит подтверждением отработки дивергенции при пробое границы тренда.

### 3.4. Очереди фракталов Билла Вильямса
- Раздельные таблицы уровней: `fractal_up` (сопротивление) и `fractal_down` (поддержка).
- Пробой `fractal_down` снизу вверх -> LONG.
- Пробой `fractal_up` сверху вниз -> SHORT.

## 5. Шпаргалка: Как устроен MACD и Дивергенция (для памяти)

### 1. Что нужно для расчета:
- Для EMA и MACD берется **строго цена закрытия свечи (close)**.
- close — это финальный итог борьбы быков и медведей за 5-минутку.

### 2. Формула EMA (Экспоненциальная средняя):
- EMA_текущая = (close * k) + (EMA_прошлая * (1 - k))
- Коэффициент веса: k = 2 / (N + 1)
  - Для EMA(12): k = 2 / 13 = 0.154 (свежая цена влияет на 15.4%, прошлая EMA — на 84.6%).
  - Для EMA(26): k = 2 / 27 = 0.074.

### 3. Формула MACD:
- **Линия MACD**: EMA(12) - EMA(26) (разница быстрой и медленной средней).
- **Сигнальная линия**: EMA(9) от линии MACD (сглаживание).
- **Гистограмма (столбики)**: Линия MACD - Сигнальная линия.

### 4. Дивергенция (расхождение цены и MACD):
- **Медвежья (вход в SHORT / вниз)**:
  - Цена: Пик 2 > Пик 1 (новый рекорд цены вверх).
  - MACD: Пик 2 < Пик 1 (столбик индикатора ниже).
  - Смысл: топливо покупателей кончилось, готовимся к падению.
- **Бычья (вход в LONG / вверх)**:
  - Цена: Дно 2 < Дно 1 (новый минимум цены вниз).
  - MACD: Дно 2 > Дно 1 (впадина индикатора выше).
  - Смысл: давление продавцов иссякло, готовимся к отскоку вверх.
