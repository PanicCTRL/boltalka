# Репозиторий «Болталка» (Архив диалогов и проектов)

В этом репозитории собраны архивы ключевых диалогов с ИИ-ассистентом, технические пояснения, математические формулы и исходный код проектов для переноса и продолжения работы на другом компьютере.

---

## 📁 Содержимое репозитория

### 1. Тексты диалогов (в удобном Markdown-формате)
* **[`dialog_1ef4b5d5_split_fractal.md`](dialog_1ef4b5d5_split_fractal.md)**:
  - Беседа `1ef4b5d5-5029-4ef6-bbe2-268b460edeee`.
  - Обсуждение архитектуры робота `split_fractal`, таймфрейма M5, индексации свечей MetaTrader-style (`candles[1..N]`).
  - Математическая база и строгие формулы: EMA, линия MACD, волны гистограммы, холмы и впадины.
  - Метод наименьших квадратов (МНК), линейная регрессия ($y = ax + b$), коэффициент корреляции Пирсона ($r$), $R^2$ и полосы среднеквадратичного отклонения ($\pm k \cdot S_e$).

* **[`dialog_current_signal.md`](dialog_current_signal.md)**:
  - Текущая беседа `f8172bb1-cd41-412b-8d91-df43af3b7bf7`.
  - Рождение проекта **SIGNAL** — визуализатора и аналитического комплекса на Python для отображения расчетов Lua.
  - Пошаговый разбор устройства графического канваса на `pyqtgraph` и `PyQt6` простыми человеческими словами.

## 🚀 Как продолжить работу на другом компьютере

1. Склонировать этот репозиторий:
   ```bash
   git clone https://github.com/PanicCTRL/boltalka.git
   ```
2. Открыть файлы в VS Code или закинуть папки проектов `SIGNAL` и `split_fractal` на рабочий диск `Y:\`.
3. В новом диалоге с ассистентом достаточно дать ссылку на `dialog_1ef4b5d5_split_fractal.md` или `TODO_SIGNAL.md`, чтобы агент сразу подхватил весь контекст и продолжил разработку с того же места!
